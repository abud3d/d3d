# مملكة دعد 👑

موقع تعليمي تفاعلي باللغة العربية لطفلة في KG2.

## التشغيل
افتحي `index.html` في المتصفح. لا يحتاج الموقع إلى خادم أو قاعدة بيانات، ويمكن رفعه كما هو إلى استضافة المواقع أو تفعيله عبر GitHub Pages.

## الموجود في النسخة الأولى
- واجهة عربية RTL متجاوبة للجوال والكمبيوتر.
- حديقة الحروف العربية مع كلمات وصور رمزية ونطق صوتي عبر المتصفح.
- الأرقام من ١ إلى ١٠ مع تمثيل بصري للعد.
- لعبة اختيار الحرف ولعبة الألوان.
- معرض صور رمزي وعداد نجوم يحفظ التقدم محلياً في المتصفح.
- لا توجد حسابات أو نماذج تجمع بيانات الطفلة.

## ملاحظات التطوير
- رسومات 👧🏻🧸 الحالية رموز مؤقتة لتمثيل ماشا والدب؛ تستبدل لاحقاً بصورة مرخصة/مناسبة للشخصيتين دون تغيير بنية الموقع.
- النطق يعتمد على أصوات اللغة العربية المتاحة في جهاز الزائر.
- التقدم محفوظ محلياً عبر localStorage على الجهاز نفسه.
